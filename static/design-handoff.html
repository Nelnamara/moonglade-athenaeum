Handoff Map — the app AS-BUILT

Authority: this card describes the current app as it exists (measured at commit 8560b8c, 2026-07-31) — it is archaeology, not a spec. Where the new design diverges from anything here, the new design wins. Nothing below is a constraint on the redesign; it exists so you know what you're replacing and what machinery (section 3) carries over.

The three host stacks today: classic gallery (moonglade_gallery.py, Flask/vanilla), the Loom (loom/master-storyboard.jsx, React), /next pilot (gallery/src, React/esbuild).

1 · The token pipeline (what is already a system)

DESIGN_TOKENS_CSS in moonglade_gallery.py is the single source — color + the five skins only. tools/export_design_kit.py regenerates static/design-tokens.css and every kit page's stamped block from it; tests/test_design_kit_sync.py fails the suite if any copy drifts.

Live drift, found by diffing the constants: the app has since added --loomc: #47cbc3 (the Loom's own hue — cyan means "the Loom" everywhere). This project's kit/design-tokens.css is refreshed with it in this push; the kit branch's stamped pages restamp automatically when the branches merge and the export script reruns. Everything else is identical — all 7 component .js files in this project are byte-identical to the live app.

5 · The measured scale (NOT yet tokens — naming them is a handoff decision)

The app defines no spacing/type/radius/breakpoint variables — these are tallies of the hardcoded values actually in use across all three surfaces (occurrences in parentheses). Recurrence = de-facto convention, nothing more.

font-size · 11px(105) · 12px(105) · 13px(62) · 10px(43) · 11.5px(40) · 12.5px(40) · 10.5px(37) · 9px(25) · 15px(15) · 14px(13) · 16px(10)
Dense-UI type runs 9–13px; 14–16px is already "large" here. Sub-pixel steps (10.5/11.5/12.5) are common.

border-radius · 6px(85) · 8px(62) · 4px(36) · 50%(35) · 5px(35) · 7px(33) · 10px(28) · 12px(28) · 999px(17 — pills) · 14px(12)

gap · 8px(64) · 6px(59) · 5px(33) · 7px(29) · 10px(27) · 9px(17) · 4px(17) · 11px(14) · 12px(12)

@media breakpoints · 480px(4) · 680px(3) · 860px(3) · plus one-offs 520/560/681/900/1023/1260
No shared breakpoint system — each surface picked its own. Relevant to the mobile question: there is nothing to "extend"; a breakpoint scale would be new either way.

z-index · two bands: components use 0–7; overlays/modals use 300–500. Nothing between.

type faces · body/UI: system-ui sans · data/ids/counts: ui-monospace · display serif (Georgia) appears exactly once in the classic app (login h1) — the serif-heading identity lives in this project's styles.css (--serif) and the mockups, not yet in the app's own tokens.
